# Noisy Provider Dumps

This directory is intentionally excluded by `.lensignore`.

It represents raw payment-provider export files that can be useful for manual debugging but are poor retrieval context:

- payloads are repetitive
- raw exports can be large
- provider fields often duplicate normalized application state
- support-safe docs and source code usually answer questions better

The file is committed so the demo repository can show that `.lensignore` is about Lens indexing behavior, not Git tracking.
