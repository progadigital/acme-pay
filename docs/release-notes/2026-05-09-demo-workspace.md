# Release Notes: Demo Workspace Expansion

Date: 2026-05-09

## What Changed

Acme Pay now includes enough cross-linked material to act as a realistic query demo workspace. The repo covers payment creation, idempotency, provider routing, webhooks, ledger entries, refunds, risk assessment, audit events, support workflows, and operational runbooks.

## Why It Matters

Demo users can ask questions that require connecting source code, architecture decisions, schema constraints, incidents, runbooks, and sample payloads.

## Good Demo Prompts

- Ask why duplicate payment requests do not create duplicate charges.
- Ask whether refund audit logging is implemented or only planned.
- Ask what happens during a provider outage.
- Ask which data is safe to log.
- Ask what blocked the fictional 2026-05-02 merchant payment.
