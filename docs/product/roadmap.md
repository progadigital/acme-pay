# Roadmap

## Milestone 1: Demo-Ready Core

- Payment intents with idempotency
- Sandbox provider
- Balanced ledger entries
- Refunds
- Webhook deduplication
- Architecture and security docs

## Milestone 2: Production Hardening

- Provider webhook signature verification
- Durable payment intent and webhook storage
- Cumulative partial refund tracking
- Refund audit events
- Risk review queue

## Milestone 3: Operational Depth

- Provider fallback routing enrollment
- Ledger reconciliation job
- Payout generation
- Dispute workflow
- Support search surface
