# Non-Goals

Acme Pay is a demo repository, not a real payment processor.

## Current Non-Goals

- Handling raw card numbers
- Storing production provider credentials
- Running a real web server
- Implementing provider settlement files
- Supporting disputes and chargebacks
- Generating real payouts

## Why These Are Excluded

The repo is meant to demonstrate repository querying, architecture exploration, and cross-file reasoning. It should be realistic enough to answer engineering questions without creating a runnable payments product.
